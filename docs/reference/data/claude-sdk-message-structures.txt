Structure of Claude Agent SDK messages, from real use
=====================================================

Source: the provider log that T3 Code keeps of every Claude Agent SDK message, on one
developer's machine. 100 log files, 96 sessions, 13 to 17 November 2026.

This file contains structure only: the kinds of message, how many of each, and each field's
name and type. It contains no values, except the values of enumeration fields (type, subtype,
status, stop_reason, role, priority). Free-form objects such as tool inputs are not expanded.
A field marked "?" is absent from some messages of that kind.

"incoming" is from the SDK to the application. "outgoing" is what T3 Code sent, in T3 Code's
own terms (query.open, prompt.offer and so on), not SDK messages.
